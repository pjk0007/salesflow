# 고객여정 구글챗 발송 기준: 60초 이상

사용자가 2026-10-13 직접 QA 후 메인 운영 반영을 요청했습니다. 운영 main에서 이번 변경만 분리했습니다. 검토 중인 방문 감사 메일 기능(PR #8)은 이 배포에 포함하지 않습니다.

## 동작

- 디자이너 하이어·백오피스랩의 고객여정 카드, 담당자 태그, 후속 대응 재알림은 해당 방문의 측정 체류가 60초 이상일 때만 보냅니다.
- 60초 미만 또는 체류 미확인은 발송하지 않습니다. 정수 duration은 실제 세션 길이로 제한하므로 59.999초가 반올림되어 60초로 저장되어도 제외합니다.
- 유효한 종료 시각만 있으면 시작과 종료 차이를 사용합니다. 여러 방문·영역 시간은 합산하지 않습니다. 마지막 활동 후 10분 대기는 유지합니다.
- 이미 대기 중인 카드와 재알림도 전송 전에 확인합니다. 이미 발송한 카드는 삭제하지 않습니다.
- Chat 조건만 충족하지 못한 방문은 status=suppressed로 보관해 CRM의 방문·관심도 판정을 유지합니다. 새 마이그레이션·환경 변수 변경은 없습니다.

## 검증

- 운영 main 기준으로 단위 테스트 156개, 실제 PostgreSQL 구문을 사용하는 격리 시나리오 22개, TypeScript 및 변경 파일 ESLint 통과.
- 두 사업의 59초/60초/59.999초/미측정, CRM 보존, 대기 카드 재확인, 재알림 선점 전후 체류 정정, 기존 내부자·봇·공유 브라우저 제외를 확인합니다.
- 운영·개발 DB에 접속하거나 실제 고객/구글챗 시험 발송을 하지 않습니다. 가상 데이터와 가짜 전송 함수를 사용합니다.
- 배포용 빌드는 별도 작업 폴더에서 실제 환경 파일을 읽지 않고 localhost의 비연결 시험 주소와 발송 off 설정으로 확인합니다.
- main의 아카이브 증빙 TS가 개발자 개인 PC 절대 경로를 import하는 문제는 docs/archive만 앱 타입 검사에서 제외해 해결합니다. 앱 소스의 strict 검사는 유지합니다.

## 배포 및 되돌리기

- 운영 서비스 sendb, Git 브랜치 main, 배포 커밋과 실행 중 상태를 확인합니다. DB와 기존 웹훅 설정은 수정하지 않습니다.
- 되돌릴 때는 이 PR의 병합 커밋을 revert해 main에 반영하고 직전 운영 버전을 재배포합니다. 데이터 삭제·복원은 필요하지 않습니다.
