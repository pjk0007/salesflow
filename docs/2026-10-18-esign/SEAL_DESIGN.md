# 전통 인장·회사 직인 디자인 개선 — 2026-10-18

기존 이름 도장의 성긴 글자와 단순 테두리를 개선해, 개인 낙관과 회사 직인을 별도로 고르게 했다. 모양 12종과 서체 3종으로 총 36개 조합을 비교한다. 서명·서버 발송·저장 방식은 기존 흐름을 사용한다.

## 리서치와 적용 판단

- 구글 이미지에서 전통 인장·회사 직인·전서체 사례를 시각 비교했다. [인장 제작사의 서체/대표인·각인 사례](https://store.shopping.yahoo.co.jp/hanco-style/ysht3cg.html)에서는 서체, 글자의 밀도와 배치가 도장 인상을 크게 바꾸는 것을 확인했다. 이번 구현은 모양과 서체를 별도 선택하도록 구성했다.
- [새김의 회사 직인 사례](https://sagim.kr/stamp/corporate/)는 상호를 외곽에, 직함을 중앙에 배치하고 사각에는 상호와 직함을 나누는 구성을 보여준다. 회사명과 가운데 글자를 따로 받으며, 입력한 회사명에 법인 구분을 임의로 덧붙이지 않는다.
- 개인 도장은 글자가 촘촘한 사각 양각/음각, 이중 원형, 세로 타원, 매화문·운문 모양을 선택한다. 회사 직인은 정통·구슬문·매화문 원형, 사각·회문·음각 모양을 선택한다. 문양과 선각 자모는 직접 작성한 경로로 그린다.

## 서체

- **전각풍 선각:** 현대 한글 자모를 직접 그린 독자적인 도장용 글자 디자인이다. 한글 11,172음절의 초성·중성·받침 조합을 지원한다. 정식 역사 전서체나 등록 인감임을 의미하지 않는다. 한글 음절 외 문자는 고전 명조로 그린다.
- **고전 명조:** Google Fonts 공식 저장소의 [나눔명조 ExtraBold](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/nanummyeongjo) 원본을 사용한다. OFL 원문과 저작권 고지를 포함했다.
- **단정한 명조:** KERIS 공식 [학교안심 상장](https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202509240000000000004) 원본을 사용한다. 공식 안내에서 상업 이용·웹/앱 탑재·수정·재배포 허용을 확인했고 OFL 원문과 저작권 고지를 포함했다.
- 두 서체 모두 원본 SHA-256을 검증하고 이름을 변경해 WOFF2로 변환했다. 글리프를 제거하지 않았으며 각각 한글 11,172자를 포함한다. 추가 전송량은 약 0.97MB이며 선택한 서체만 자체 서버에서 지연 로딩한다. 원본·출처·해시는 `public/esign/fonts/seal-sources.json`, 재현 도구는 `scripts/prepare-esign-seal-fonts.py`다.

## UX와 출력

1. 이름 도장에서 개인 도장/회사 직인을 고른다.
2. 개인은 이름 2~8자, 회사는 회사명 2~24자와 가운데 글자 1~8자를 입력한다. 도장 글자는 공백을 제거한다.
3. 서체와 시안을 비교해 선택한 후 문서에 넣는다. 이름·회사명·직함·서체 변경 시 이전 선택을 해제한다.
4. 최종 확인 화면에서 모양과 위치를 확인하고 제출한다. 선택 PNG를 기존 이미지 예산 안으로 정규화해 완료 PDF에 넣는다. 음각의 글자는 투명하게 비워 실제 문서 바탕이 보이게 한다.

이름·회사명은 외부 폰트 서버나 AI 서비스에 보내지 않는다. 추가 DB·서버 도장 생성 작업·새 발송 채널은 없다.

## 검수 근거

- 격리 가상 브라우저에서 36개 조합과 8자 개인 이름·24자 회사명의 시안 12개를 검사했다. 서체별/모양별 이미지가 다르고 글자 바깥 여백이 유지되는지 확인했다.
- 375×812 화면에서 가로 넘침, 서체/직함 변경 후 선택 해제, 기존 손글씨 서명 4종을 확인했다.
- 전각풍 음각과 매화문 회사 직인을 선택해 가상 계약서를 완료했다. 완료 PDF 42,369bytes, SHA-256 `9ea310d11ef5110bb64b62c32dfef98c5a0d056346bc640a0e5fcb3469e52492`가 확인 기록과 일치한다. 최종 확인 PNG 4개의 픽셀이 PDF에 보존되며 개별 80,000px/83,886bytes 한도를 지킨다.
