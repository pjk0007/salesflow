# 첨부 예시 기준 도장 교체 — 2026-10-18

사용자는 예시에 나온 도장 서체 계열만 쓰도록 교체를 요청했고, 출처 질문에는 ‘몰라’라고 답했다. 이미지에 나온 상용 원본은 확인하지 못했다. 이번 한글 3종은 예시의 형태를 참고한 **새 샌드비 도안**이며 동일 원본 폰트라고 표시하지 않는다. 한자는 공개된 CNS11643의 실제 전서체를 사용한다.

## 변경한 선택지

- 기존 `전각풍 선각`, `고전 명조`, `단정한 명조`와 도장용 기존 WOFF2·생성 코드를 제거했다.
- 새 한글 선택지는 **둥근 도안체·전서 도안체·길상 도안체**다. 기존 선각의 이름만 바꾸지 않고, 새 획 윤곽과 글자 조합을 WOFF2로 생성했다. 한글 11,172음절과 ASCII 95자를 포함한다. 한자는 같은 공개 전서체의 획 두께를 선택한 도안에 맞춰 표현한다.
- 원형·타원·사각 양각/음각, 회사 원형 직인의 원·별·마름모·삼각 표시와 사각 직인만 제공한다. 예시에 없던 꽃 테두리·구슬문·운문은 제거했다.
- 회사 상호를 원 둘레에 배치하고 가운데 직함을 채운다. `대표이사`와 `代表理事` 예시 버튼을 제공하지만 회사명·법인 구분·이름을 자동 번역하거나 추가하지 않는다.
- 서체·회사명·직함 변경 시 선택을 해제한다. 지원하지 않는 글자는 시스템 명조체로 조용히 대체하지 않고 안내한다. 예를 들어 이 공개 전서체에 없는 `韓`은 입력 안내가 나온다.

## 구조와 출처

DB·발송·서버 저장·완료 PDF 처리에는 변경이 없다. 모든 글자 생성은 고객 브라우저에서 수행한다. 이름을 외부 폰트 서버나 AI에 보내지 않는다. 한글 글꼴은 약 36~42KB이며 선택한 것만 읽는다. 한자 전체 약 7.13MB는 128 코드포인트 묶음 164개로 나눠 입력 글자에 필요한 파일만 읽는다. `代表理事`는 3묶음 **121,624bytes**다.

새 한글 도안은 독자적인 디자인이며 정식 역사 전서체 또는 등록 인감을 뜻하지 않는다. ASCII는 기존 SIL OFL의 Nanum Brush Script에서 가져왔다. 한자 원본·사용 조건·재현 도구와 배포 고지는 [SEAL_DESIGN.md](./SEAL_DESIGN.md), `public/esign/fonts/reference-seal-sources.json` 및 OFL 파일을 따른다.
