# 샌드비 고객 플랫폼 대체 목표

## 원래 목표와 완료 기준

백오피스랩과 디자이너하이어가 API/SDK로 설치·연결하여 채널톡·인터컴·허브스팟에서 필요한 상담·고객관리·자동화 업무를 샌드비로 대체할 수 있게 한다. 단순 화면 복제나 웹 채팅만으로 완료로 판단하지 않는다. 두 사업의 고객 식별과 데이터 격리, 상담, CRM, 자동화, 데이터 이전, 운영 검증이 실제로 이어져야 한다.

기존 운영 변경은 개발자 검토와 별도 운영 반영 요청 후 수행한다. 검증은 격리 환경·가상 고객으로 하며 실제 고객에게 알림이나 대화를 발송하지 않는다. 이 배포 절차는 제품 구현 범위를 축소하는 조건이 아니다.

## 진행 원칙

상담 화면을 완성했다고 전체 목표를 달성했다고 쓰지 않는다. SDK/문서 분석은 서버 기능이나 실제 계정 업무를 관찰한 증거가 아니다. 요구사항마다 구현 파일·테스트·브라우저 결과·남은 작업을 갱신하고, 필요한 근거가 빠지면 목표를 계속 진행 상태로 둔다.

첫 확장은 R02~R04의 공통 기반이다. 서버 API 토큰으로 고객·회사·회원 세션을 연결하고, 브라우저에는 짧은 수명의 회원 증명만 전달한다. 이후 R05~R16까지 같은 고객 ID와 이벤트 계약을 사용해 확장한다.
