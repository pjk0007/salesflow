# 상담 AI 승인 지식과 실제 모델 검수

2026-10-17 사용자가 공개 서비스 근거 8개 승인·연결과 가상 문항 6개의 실제 모델 검수를 승인했다. 디하 사업(8)에 지식 #36, 백오피스랩 사업(9)에 지식 #37을 등록·승인하고 각각 수동 초안 설정에 연결했다. 두 버전 모두 상담용 사실 4개이며 메일 지식 연결은 변경하지 않았다.

## 사용 방법

1. 샌드비의 고객 상담에서 새 문의를 연다.
2. `AI 답변 도우미`를 펼치고 `현재 상담 초안 생성`을 누른다.
3. 초안과 인용된 근거를 확인하고 상담원이 답변을 결정한다. 근거가 부족한 질문은 상담원이 이어서 안내한다.
4. 근거를 추가하려면 `/customer-ai`에서 사업을 선택하고 새 지식 버전을 만든 뒤 사실·URL·확인일을 검토해 승인한다. 승인 후 설정에서 해당 버전을 선택하고 적용한다.

응대 방식은 `수동 초안`이며 자동 응대 워커는 꺼져 있다. 이번 작업으로 고객에게 답변을 자동 전송하지 않는다. 백오피스랩 사이트의 실제 상담창 전환은 별도 승인 대상이다.

## 실제 모델에서 발견한 문제와 보완

기존 근거 검수 프롬프트에 JSON 형식 요청은 있었지만 모델이 코드 블록 뒤에 분석 설명을 붙였다. 파서는 이를 거절해 정상 답변도 인계 처리했다. 검수 프롬프트에 유효한 JSON 객체 하나만 반환하고 코드 블록·설명·추가 텍스트를 출력하지 않도록 명시했다. 파서나 근거 기준을 완화하지 않았다. 추가 텍스트 및 두 JSON 객체를 거절하는 회귀 검사를 유지한다.

규칙 테스트 5개 통과. 타입·린트·운영 빌드 및 배포 후 실제 상담 화면 결과는 배포 기록에 추가한다. 실제 고객 발송과 운영 DB 직접 조회·스키마 변경은 없다.
