예시의 고객·회사는 모두 가상입니다.

이 페이지에서는 설명과 검수 화면만 봅니다. 실제 답장·저장·게시·가져오기는 실행하지 않습니다.

시작 전: 사업 선택과 직원 역할 확인

같은 메뉴라도 배정받은 사업과 역할에 따라 사용할 수 있는 기능이 달라집니다. 사업이 보이지 않으면 조직 관리자에게 고객 상담 → 직원 권한의 배정을 요청하세요. 상담팀에 들어가는 것만으로 사업 접근 권한이 생기지는 않습니다.

    관련 검수 화면

    기능 검수 당시 가상 화면입니다. 최신 개발본과의 동일성이나 운영 적용을 의미하지 않습니다. 화면의 검수 전용 제어는 실제 제품 사용 절차에 포함하지 않습니다.

    고객에게는 어떻게 보이나요?

    문의 목록에서 이전 문의를 다시 열거나 새 문의를 시작하고, 메시지에 파일을 붙일 수 있습니다. 아래는 실제 사이트에 설치한 화면이 아닌, 별도 검수 환경의 가상 고객 화면입니다.

    이어서 볼 업무

    관리자 추가 안내: 권한·업무시간·성과·보관과 복구

    직원 권한

    고객 상담 → 직원 권한
    조직 관리자가 사업별 역할을 배정·회수합니다. 운영 관리자는 다른 직원의 사업 권한을 배정할 수 없습니다. 권한 회수는 이미 저장한 발송의 취소를 보장하지 않습니다.

    업무시간·응대 목표

    고객 상담 → 운영·성과 → 업무시간·응대 목표
    운영 관리자가 요일·휴무·고객 안내와 첫/추가 답변·해결 목표를 검토한 뒤 운영 설정 저장을 누릅니다. 목표는 기본 꺼짐이며 변경은 새 응대부터 적용합니다. 목표 설정과 자동 초과 알림 실행 준비는 별도입니다.

    응대 성과

    고객 상담 → 운영·성과 → 응대 성과
    날짜·상담 매체를 선택해 첫 답변/해결 중앙값과 표본, 목표 준수·초과, 담당자별 결과를 확인합니다. 해당 기간에 시작한 응대 기준이며 표본이 없으면 —로 표시합니다. 과거 보관 상담과 내부 고객은 집계에서 제외합니다.

    고객·회사 보관과 복구

    고객 관리 → 고객 / 회사 → 항목 열기
    운영 관리자가 입력을 먼저 저장하고 보관하기 → 영향 확인 → 보관 실행을 진행합니다. 보관함에서 보관 복구 → 복구 실행으로 다시 사용합니다. 영구 삭제나 고객 계정 정지가 아니며 기존 업무는 취소하지 않습니다. 중단한 자동화도 복구만으로 재개하지 않습니다.

    이 안내는 현재 개발본의 진입 방법입니다. 전체 보존 기간·영구 파기·선택 복구 정책과 고급 분석·여러 응대 목표 정책은 후속 범위입니다. 근거 문서는 검증 기록의 sourceReferences에 연결했습니다.

    개발 검토용 안내 · 실제 사이트 설치, 계정 연결, 전체 자료 이전과 현업 인수는 별도 확인이 필요합니다.

    이 가이드의 기준과 검증 범위

    기능별 가상 검수 화면과 업무 설명을 연결했습니다. 캡처 시점과 현재 개발 서버의 화면은 다를 수 있습니다. 화면마다 촬영 범위가 다르며 전체 업무의 운영 검증을 뜻하지 않습니다. 이 페이지는 네트워크 요청 없이 동작하는 오프라인 설명 자료입니다.

    첨부와 본문 초안의 수명, 읽기 전용 기록, 사람의 게시·전송, 기본 꺼짐 상태를 구분했습니다. 이 가이드는 설명 자료이며, 실제 기능은 개발 샌드비에서 사용합니다. 캡처가 운영 배포를 의미하지는 않습니다.
