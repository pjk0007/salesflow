이전 상담은 어떻게 보이나요?

직원은 이전 상담과 내부 메모를 볼 수 있습니다. 고객 본인에게는 관리자가 원본 회원 ID와 사이트 회원 ID의 일치를 확인한 공개 기록만 읽기 전용으로 표시합니다.

이전 상담에 새 답변을 붙이지 않고 새 문의로 상담 시작하기에서 이어갑니다. 작성하던 새 문의 문구는 이전 기록을 왕복해도 유지됩니다.

실제 사이트 로그인 연결과 원본 회원 매핑은 별도 설치 확인이 필요합니다. 이번 예시 가져오기는 직원 보관용이며 고객 공개를 승인하지 않습니다.
