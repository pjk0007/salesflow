3. 상담에서 이전 경로 확인

  2. 직원 상담함에서 새 문의를 열고 오른쪽 발송·방문·상담 경로를 확인합니다.
  3. ‘메일 링크 유입 · 본인 미확인’과 가상 메일·알림톡 기록, 방문 페이지, 현재 문의가 표시됩니다.

회원 연결도 체험하려면 문의를 보낸 뒤 아래 버튼을 누르세요. 실제 사이트 로그인 대신 고정된 가상 회원을 사용합니다.

이 예시는 새 샌드비 상담창의 연결 검수용입니다. 실제 채널톡 계정이나 디하·백오피스랩 운영 사이트는 변경하지 않습니다.
